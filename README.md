# Customer Churn Prediction for OTT and Lifestyle Services

An end-to-end machine-learning project that predicts customer churn risk for a simulated OTT and lifestyle subscription business.

The project covers the complete batch ML workflow: synthetic data generation, exploratory data analysis, feature engineering, model training, customer scoring, and export of high-risk customers for retention-focused action.

> **Important:** This project uses a synthetic dataset generated by `generate_ott_churn_lifestyle.py`. It does not use real customer or company data.

---

## Problem Statement

Subscription businesses lose revenue when customers cancel or stop renewing their subscriptions. The goal of this project is to identify customers with a higher probability of churn so that a retention team can prioritize outreach, personalized offers, or service improvements.

Given customer lifestyle, usage, subscription, and engagement attributes, the model predicts a churn-risk score for each customer.

## Model Evaluation Guidance

For churn prediction, accuracy alone can be misleading when churned customers are less common than retained customers. The most useful metrics depend on the business cost of errors:

| Metric | Why it matters |
|---|---|
| Precision | Of customers predicted to churn, how many actually churned? |
| Recall | Of customers who churned, how many did the model identify? |
| F1-score | Balances precision and recall |
| ROC-AUC | Measures ranking quality across classification thresholds |
| Confusion matrix | Shows false positives and false negatives clearly |

For a retention campaign, high recall may be important if missing a likely-to-churn customer is costly. If outreach is expensive, a higher-precision threshold may be more appropriate.

## Limitations

- The dataset is synthetic and may not reflect real customer behaviour or real-world data quality.
- The project is a batch-scoring workflow, not a deployed real-time prediction service.
- Results depend on the data-generation assumptions and feature design.
- The project does not currently include drift monitoring, scheduled retraining, model explainability, or production-grade feature serving.
- Churn predictions should be validated with business owners and real historical data before use in a real retention program.
